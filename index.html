Рационал сандар деген не?

Бүтін сандар мен бөлшек сандардың жиыны рационал сандар деп аталады. Рационал санды m/n түрінде жазуға болады: m — бүтін сан, n — натурал сан.

−5; 0; {3/4}; −1,25; −{2/7}
Қарама-қарсы сандар тек таңбасымен ерекшеленеді, қосындысы нөлге тең: {3/4} және −{3/4}.
Санның модулі — оның координаталық түзудегі нөлден қашықтығы: |−{3/4}| = {3/4}.

Қосу

Таңбалары бірдей сандарды қосқанда модульдерін қосып, алдына ортақ таңбаны жазамыз.
−{2/7} + (−{3/7}) = −{5/7}
Таңбалары әртүрлі сандарды қосқанда үлкен модульден кіші модульді азайтып, модулі үлкен санның таңбасын қоямыз.
−{3/4} + {1/2} = −{3/4} + {2/4} = −{1/4}Алдымен бөлшектерді ортақ бөлімге келтірдік.
−1,5 + 4,2 = 4,2 − 1,5 = 2,7

Азайту

Азайтқышқа қарама-қарсы санды қосамыз: a − b = a + (−b).
{2/3} − {5/6} = {2/3} + (−{5/6}) = {4/6} − {5/6} = −{1/6}
5 − (−2) = 5 + 2 = 7

Көбейту

Таңба ережесі: таңбалары бірдей болса, көбейтінді оң; әртүрлі болса, теріс.
×+−
++−
−−+

Бөлшектерді көбейткенде алымын алымына, бөлімін бөліміне көбейтеміз. Мүмкін болса, қысқартамыз.

−{2/5} · {3/4} = −{6/20} = −{3/10}
(−4) · (−5) = 20

Бөлу

Бөлінгішті бөлгіштің кері санына көбейтеміз: a : b = a · {1/b}. Таңба ережесі көбейтумен бірдей.
−{3/8} : (−{9/16}) = −{3/8} · (−{16/9}) = {48/72} = {2/3}
−6 : {3/2} = −6 · {2/3} = −4

Нөлге бөлуге болмайды!

Амалдар реті

1) жақша ішіндегі амал; 2) көбейту мен бөлу, солдан оңға қарай; 3) қосу мен азайту, солдан оңға қарай.
−8 : 4 + 3 · (−2) = −2 + (−6) = −8
